AMBIGOVEETV 1.6.1 — COMBINÉE
================================

Cette version contient ENSEMBLE :

- l'interface et la gestion des appareils de la 1.5 ;
- connexion / déconnexion de chaque Govee ;
- ajout, suppression et changement de position ;
- multi-lampes ;
- aucune barre de luminosité manuelle ;
- association / déconnexion Philips ;
- mise à jour automatique depuis GitHub Releases.

POUR GITHUB
-----------

1. Envoie le contenu de ce dossier à la racine du dépôt.
2. Commit sur `main`.
3. Vérifie que l'Action Android build passe en vert.
4. Pour déclencher une mise à jour sur les TV, publie ensuite une Release/tag :
   v1.6.1

La Release doit contenir :
- AmbiGoveeTV.apk
- AmbiGoveeTV-Windows.zip

L'app sur la TV vérifie `releases/latest` au lancement.
Un simple commit sur `main` ne suffit pas : il faut une Release.

SIGNATURE
---------

Toutes les versions destinées aux mises à jour doivent être signées avec la même
clé Android permanente. Sinon Android refusera de remplacer l'APK installée.
